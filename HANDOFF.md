## The home "network hero" (most recent work)
Instead of a wildlife photo, the homepage hero is a **plain cream background with a live
social-network graph** in the space to the right of the title (nods to my social-network research):
- Built as an **animated inline SVG** (not a GIF) by the last `<script>` in `assets/html/site-js.html`.
- Nodes are spread **evenly** via a jittered grid; each links to nearest neighbors + a few longer
  bridges (no tight clusters; ~3–4 connections/node).
- **Animation:** periodically a clay pulse travels along an edge node→node (a **food-sharing event**),
  the edge lights up, the receiver rings. ~1–2 edges lit at a time. Respects prefers-reduced-motion.
- Network column width is controlled in `.hero__grid` (`grid-template-columns`) in site.css; node
  count / speed are in the animation script. On <860px it stacks (title full-width, network below).
- `assets/img/network.svg` (a static version) exists but the hero uses the JS-animated one.
